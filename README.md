Supermarket Sales Dashboard

Project Overview

An interactive supermarket sales dashboard developed using Microsoft Excel to analyze sales performance and identify useful business insights.

Tools and Skills

- Microsoft Excel
- PivotTables
- Excel formulas
- Charts and data visualization
- Interactive slicers

Project Objectives

- Analyze overall sales performance.
- Compare sales across product categories and branches.
- Identify sales trends and patterns.
- Present important business metrics in an interactive dashboard.

Key Learnings

- Organizing and analyzing sales data.
- Creating PivotTables, charts, and slicers.
- Presenting business information through a dashboard.
